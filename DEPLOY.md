# 🚀 Деплой в интернет — пошаговая инструкция

Всё приложение (сайт + API + база данных) разворачивается **одним сервисом на
[Render](https://render.com)** — бесплатно. Регистрация через GitHub, ~5 минут.

---

## Шаг 1. Деплой на Render

1. Зайдите на https://render.com и войдите через **GitHub**.
2. Нажмите **New → Blueprint**.
3. Выберите репозиторий `payment-calendar` (дайте Render доступ к нему,
   если попросит). Render найдёт файл `render.yaml` и предложит создать
   **web-сервис + базу PostgreSQL** — подтвердите.
4. Перед созданием задайте пароль администратора:
   - `FIRST_ADMIN_PASSWORD` → придумайте надёжный пароль (это вход в систему).
   - `SECRET_KEY` сгенерируется автоматически.
5. Нажмите **Apply / Create**. Render соберёт приложение (первая сборка
   занимает 5–10 минут).
6. Когда статус станет **Live** — скопируйте адрес сервиса, например:
   `https://payment-calendar.onrender.com`

**Это уже рабочая ссылка на сайт.** Откройте её и войдите:
- **Email:** `admin@innowave.group`
- **Пароль:** тот, что задали в `FIRST_ADMIN_PASSWORD`

> ⚠️ На бесплатном тарифе сервис «засыпает» после 15 минут простоя —
> первый запрос после паузы грузится ~30–60 секунд. Это нормально.
> Если мешает — тариф Starter ($7/мес) держит сервис всегда активным.

## Шаг 2 (необязательно). Свой домен

Календарь можно повесить на ваш домен — например
`calendar.innowavehygiene.com` или `calendar.innowave-group.com`.
Рекомендуется именно **поддомен**: корневой домен остаётся под сайт компании,
и существующие сайт/почта не затрагиваются.

### 2.1. Добавить домен в Render

Дашборд Render → ваш сервис → **Settings → Custom Domains → Add Custom
Domain** → введите, например:

```
calendar.innowavehygiene.com
```

Render покажет значение CNAME (ваш адрес `*.onrender.com`).

### 2.2. Добавить DNS-запись

Где добавлять — зависит от того, где обслуживается DNS вашего домена:

**Домен innowavehygiene.com** (DNS в Google Cloud):
[console.cloud.google.com](https://console.cloud.google.com) →
**Network Services → Cloud DNS** → зона `innowavehygiene.com` →
**Add record set**:

| Поле | Значение |
|---|---|
| DNS name | `calendar` |
| Type | `CNAME` |
| Data | `payment-calendar.onrender.com.` ← **с точкой на конце** |

**Домен на Cloudflare** (если купите новый там):
Dashboard → домен → **DNS → Add record**:

| Поле | Значение |
|---|---|
| Type | `CNAME` |
| Name | `calendar` |
| Target | `payment-calendar.onrender.com` |
| Proxy status | **DNS only** (серое облачко, не оранжевое!) |

### 2.3. Подождать

DNS обновляется от пары минут до часа. Render сам проверит запись и выпустит
HTTPS-сертификат. После этого сайт доступен по вашему домену.

## Обновление приложения

Любой `git push` в ветку автоматически пересобирает сервис на Render —
вручную ничего делать не нужно.

## Возможные нюансы

- **«Сайт долго не открывается»** — бесплатный сервис проснулся после простоя,
  подождите ~30–60 сек и обновите страницу.
- **Домен не подтверждается в Render** — проверьте, что CNAME-запись создана
  точно с тем значением, которое показал Render, и прошло достаточно времени.
  В Cloudflare — что стоит «DNS only» (серое облачко).
- **Данные пропали после редеплоя** — убедитесь, что `DATABASE_URL` берётся из
  базы PostgreSQL (через `render.yaml` это уже настроено), а не из SQLite.

## Локальный запуск для разработки

Как и раньше: backend — `uvicorn app.main:app --reload` (порт 8000),
frontend — `npm run dev` (порт 5173, проксирует `/api` на backend).
