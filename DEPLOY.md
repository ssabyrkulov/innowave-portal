# 🚀 Деплой в интернет — пошаговая инструкция

Разворачиваем приложение бесплатно:
- **Backend + база PostgreSQL** → [Render](https://render.com)
- **Frontend** → [Vercel](https://vercel.com)

Оба сервиса входят через ваш GitHub-аккаунт. Времени — ~10 минут.

---

## Шаг 0. Запушьте код на GitHub

Код уже в ветке `claude/innowave-group-calendar-81tcby` репозитория
`ssabyrkulov/payment-calendar`. Можно деплоить прямо с неё или слить в `main`.

---

## Шаг 1. Backend на Render

1. Зайдите на https://render.com и войдите через **GitHub**.
2. Нажмите **New → Blueprint**.
3. Выберите репозиторий `payment-calendar`. Render найдёт файл `render.yaml`
   и предложит создать **web-сервис + базу PostgreSQL** — подтвердите.
4. В настройках перед созданием задайте секретный пароль администратора:
   - `FIRST_ADMIN_PASSWORD` → придумайте надёжный пароль (это вход в систему).
   - `SECRET_KEY` сгенерируется автоматически.
5. Нажмите **Apply / Create**. Render соберёт Docker-образ и запустит сервис.
6. Когда статус станет **Live**, скопируйте адрес сервиса, например:
   `https://payment-calendar-api.onrender.com`

> ⚠️ На бесплатном тарифе сервис «засыпает» после 15 минут простоя —
> первый запрос после паузы может грузиться ~30 секунд. Это нормально.

Проверка: откройте `https://<ваш-адрес>.onrender.com/` — должно вернуться
`{"status":"ok","service":"payment-calendar"}`.

---

## Шаг 2. Frontend на Vercel

1. Зайдите на https://vercel.com и войдите через **GitHub**.
2. **Add New → Project** → выберите репозиторий `payment-calendar`.
3. В настройках проекта:
   - **Root Directory** → укажите `frontend`
   - **Framework Preset** → Vite (определится сам)
4. Откройте **Environment Variables** и добавьте:

   | Name | Value |
   |------|-------|
   | `VITE_API_BASE` | `https://payment-calendar-api.onrender.com` |

   (адрес вашего backend из шага 1, **без** слэша в конце)
5. Нажмите **Deploy**. Через минуту получите адрес вида
   `https://payment-calendar.vercel.app` — **это и есть ваша ссылка на сайт.** 🎉

---

## Шаг 3. Связать фронт и бэк (CORS)

Чтобы браузер разрешил запросы с Vercel на Render:

1. Вернитесь в Render → ваш сервис → **Environment**.
2. Измените переменную `CORS_ORIGINS` со `*` на адрес вашего фронтенда:
   ```
   https://payment-calendar.vercel.app
   ```
3. Сохраните — сервис перезапустится.

> Можно оставить `*` (работает, т.к. авторизация на Bearer-токенах, а не cookie),
> но указать конкретный домен — безопаснее.

## Готово ✅

Откройте адрес с Vercel и войдите:
- **Email:** `admin@innowave.group`
- **Пароль:** тот, что задали в `FIRST_ADMIN_PASSWORD`

Дальше через раздел **Пользователи** заведите коллег из InnoWave и раздайте роли.

## Обновление приложения

Любой `git push` в ветку автоматически пересоберёт и Render, и Vercel —
ничего вручную делать не нужно.

## Возможные нюансы

- **«Сайт не отвечает» при первом входе** — backend на free-тарифе проснулся,
  подождите ~30 сек и обновите страницу.
- **Ошибка входа / CORS в консоли** — проверьте, что `VITE_API_BASE` на Vercel
  и `CORS_ORIGINS` на Render указывают на правильные адреса.
- **Данные пропали после редеплоя** — убедитесь, что `DATABASE_URL` берётся из
  базы PostgreSQL (через `render.yaml` это уже настроено), а не из SQLite.
