# Чат-бот салона «Байкан» (Telegram)

Бот для клиентов салона красоты:

- **💇 Услуги и цены**: прайс из `salon.json`
- **📝 Записаться**: пошаговая заявка (услуга → удобное время → имя → телефон).
  Заявка сохраняется в SQLite и уходит в чат администратора с кнопками
  «✅ Подтвердить / ❌ Отклонить». Клиенту автоматически приходит ответ.
- **📍 Адрес и часы**, **☎️ Связаться с администратором**
- **Свободные вопросы** («есть ли у вас кератин?», «до скольки работаете в воскресенье?»):
  отвечает Claude, только по сведениям из `salon.json`. Цены и время он не выдумывает.
  Без `ANTHROPIC_API_KEY` бот работает только по кнопкам.

## Запуск

1. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен.
2. Заполните `salon.json` реальными адресом, телефоном, услугами и ценами (сейчас там примеры).
3. Скопируйте `.env.example` в `.env` и заполните `BOT_TOKEN`, при желании `ANTHROPIC_API_KEY`.
4. Запустите:
   ```bash
   pip install -r requirements.txt
   python -m bot.main
   ```
5. Добавьте бота в группу администраторов (или напишите ему в личку), отправьте `/chatid`,
   впишите полученный номер в `ADMIN_CHAT_ID` и перезапустите бота.

Docker: `docker build -t baikan-bot . && docker run --env-file .env -v $PWD/data:/app/data -e DB_PATH=data/bookings.db baikan-bot`.
Бот работает через long polling, поэтому внешний адрес и вебхук не нужны. Подойдёт любой сервер
или Render *Background Worker*.
