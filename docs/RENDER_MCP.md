# Render MCP — управление хостингом прямо из Claude

Подключает Claude к нашему аккаунту Render, чтобы можно было смотреть
сервисы, базы, логи и метрики — и чинить аварии, не лазая руками в дашборд.

Настройка уже лежит в репозитории (`.mcp.json`), секретов там нет —
авторизация идёт через OAuth, API-ключ нигде не хранится.

## Как включить (один раз в каждой новой сессии/машине)

1. Открыть Claude Code в папке проекта.
2. Набрать команду `/mcp`.
3. Выбрать **render** → **Authenticate**.
4. Завершить вход в браузере под аккаунтом Render.

После этого Claude видит инструменты Render.

> MCP-серверы подхватываются **при старте сессии**. Если `render` не видно в
> списке — перезапустите сессию Claude Code.

## Что становится доступно

- **Сервисы**: список, детали, **правка переменных окружения**
- **Деплои**: запустить передеплой, посмотреть историю
- **Логи**: выборка по фильтрам (ошибки, период)
- **Метрики**: CPU/память, число подключений к базе, коды ответов
- **Postgres**: список баз, детали, **read-only SQL-запрос** к базе

## Зачем это нам (реальные примеры)

- «Почему сайт отдаёт 502?» — Claude сам поднимет логи и найдёт причину.
- Авария с `DATABASE_URL` (июль 2026): сервис смотрел на удалённую базу,
  чинилось правкой переменной — с MCP это делается за один запрос.
- «Хватает ли памяти инстансу?» — посмотреть метрики перед апгрейдом тарифа.

## Осторожно

OAuth даёт доступ **ко всем воркспейсам и сервисам** аккаунта, а сервер умеет
**менять переменные окружения и запускать деплои**. Перед изменениями Claude
должен показывать, что собирается сделать, и согласовывать.

Официальная документация: https://render.com/docs/mcp-server
