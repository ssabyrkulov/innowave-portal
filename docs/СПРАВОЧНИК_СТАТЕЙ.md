# Справочник статей — ДДС и доходов/расходов (проект)

> **Статус:** проект для согласования с бухгалтером. Это методологическая
> основа для БДДС (движение денег) и БДР (прибыль), а также для план-факта
> в портале. Сверьте с тем, что уже заведено в 1С — не плодите дубли,
> переиспользуйте существующие статьи, где они есть.

## Зачем два справочника (и чем отличаются)

- **Статьи ДДС** — классифицируют **движение денег** (поступило/заплатили).
  Основа отчёта **БДДС** и платёжного календаря. Отвечают на вопрос
  «на что ушли деньги».
- **Статьи доходов/расходов** — классифицируют **начисление** (выручка и
  затраты по методу начисления). Основа **БДР / ОПиУ** (прибыль).

Списки пересекаются (зарплата, аренда, реклама есть в обоих), но **не
совпадают**. Классические расхождения:

| Операция | Статья ДДС (деньги) | Статья Р/Д (прибыль) |
|---|---|---|
| Оплатили товар поставщику | **Закуп товара** (выплата) | — (ложится в запас 1610) |
| Продали товар | — | **Себестоимость реализации** (7110) |
| Купили оборудование | **Покупка ОС** (инвестиц.) | — (амортизируется годами) |
| Начислили амортизацию | — | **Амортизация** |

Форма БДР (порядок строк):
```
Выручка (Д01)
− Себестоимость (Р01)
= Валовая прибыль
− Коммерческие расходы (Р1x)
− Административные расходы (Р2x)
= Операционная прибыль (EBIT)
± Прочие доходы/расходы (Д0x / Р3x)
− Финансовые расходы (Р41)
= Прибыль до налога
− Налог на прибыль
= Чистая прибыль
```

## 4. Что уточнить у бухгалтера

- Какие статьи **уже заведены в 1С** (переиспользуем, не дублируем).
- Обязательность статьи (субконто) на счетах ДДС и на 6110/7110 —
  чтобы пустых не было (см. учётную политику, п. 7.2 и п. 3).
- Нужен ли разрез по **направлениям** (подгузники / салфетки / ONE classic)
  на уровне статей, или направление берётся из номенклатуры.
- Нужны ли **ЦФО** (центры ответственности) — если планируете бюджеты по
  подразделениям.
