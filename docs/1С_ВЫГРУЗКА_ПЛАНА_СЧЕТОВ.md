# Как выгрузить план счетов из 1С

> Нужен полный справочник счетов каждой базы: код, наименование, тип,
> признаки (валютный/количественный/забалансовый) и список субконто. Портал
> будет строить по нему ОСВ, Баланс и P&L — вместо зашитого списка.
> Сделать нужно **дважды**: по управленческой Хайджин и по управленческой
> Инновейв (у второй появляются счета НДС/НСП, которых у первой нет).

## Способ 1 — вручную, 2 минуты (рекомендую начать с него)

1. В 1С открыть **Главное → План счетов** (в некоторых конфигурациях —
   *Справочники → План счетов бухгалтерского учёта*).
2. В открывшемся списке нажать **Ещё → Вывести список…**
   (кнопка «Ещё» — в правом верхнем углу списка).
3. В окне «Вывести список» отметить колонки. Обязательно:
   **Код**, **Наименование**, **Вид счёта** (активный/пассивный/АП),
   **Забалансовый**, **Валютный**, **Количественный**,
   **Субконто1**, **Субконто2**, **Субконто3**.
   Если каких-то колонок нет в списке — оставить те, что есть.
4. Тип вывода — **Табличный документ**, нажать **ОК**.
5. В полученной таблице: **Файл → Сохранить как…** → тип файла
   **Лист Excel 2007 (.xlsx)** → имя:
   - `Хайджин_УПРАВЛЕНКА_План счетов.xlsx`
   - `Инновейв_УПРАВЛЕНКА_План счетов.xlsx`
6. Положить в папку Drive соответствующей фирмы (ту же, куда едут остальные
   выгрузки).

Важно: **над таблицей не должно быть служебных строк** («Список», «Отчёт
сформирован…»). Если 1С добавила заголовок — удалить строки так, чтобы
первая строка была шапкой колонок.

## Способ 2 — процедурой в модуле (когда нужно автоматически)

Добавляется в тот же модуль, где живут остальные выгрузки, и ставится на
регламент вместе с ними. План счетов меняется редко — достаточно раза в
сутки.

```bsl
Процедура ВыгрузитьПланСчетов(ПутьКФайлу) Экспорт

    ТЗ = Новый ТаблицаЗначений;
    ТЗ.Колонки.Добавить("Код");
    ТЗ.Колонки.Добавить("Наименование");
    ТЗ.Колонки.Добавить("ВидСчета");
    ТЗ.Колонки.Добавить("Забалансовый");
    ТЗ.Колонки.Добавить("Валютный");
    ТЗ.Колонки.Добавить("Количественный");
    ТЗ.Колонки.Добавить("Родитель");
    ТЗ.Колонки.Добавить("Субконто1");
    ТЗ.Колонки.Добавить("Субконто2");
    ТЗ.Колонки.Добавить("Субконто3");
    ТЗ.Колонки.Добавить("ПометкаУдаления");
    ТЗ.Колонки.Добавить("СчетGUID");

    Выборка = ПланыСчетов.Хозрасчетный.Выбрать();
    Пока Выборка.Следующий() Цикл
        Стр = ТЗ.Добавить();
        Стр.Код             = Выборка.Код;
        Стр.Наименование    = Выборка.Наименование;
        Стр.ВидСчета        = Строка(Выборка.Вид);
        Стр.Забалансовый    = ?(Выборка.Забалансовый, "Да", "Нет");
        Стр.Валютный        = ?(Выборка.Валютный, "Да", "Нет");
        Стр.Количественный  = ?(Выборка.Количественный, "Да", "Нет");
        Стр.Родитель        = Строка(Выборка.Родитель);
        Стр.ПометкаУдаления = ?(Выборка.ПометкаУдаления, "Да", "Нет");
        Стр.СчетGUID        = Строка(Выборка.Ссылка.УникальныйИдентификатор());

        // Виды субконто — отдельная табличная часть счёта.
        Счет = Выборка.Ссылка.ПолучитьОбъект();
        Для Инд = 1 По 3 Цикл
            Если Счет.ВидыСубконто.Количество() >= Инд Тогда
                Стр["Субконто" + Инд] =
                    Строка(Счет.ВидыСубконто[Инд - 1].ВидСубконто);
            КонецЕсли;
        КонецЦикла;
    КонецЦикла;

    // Выгрузка в лист Excel: числа — числами, первая строка — шапка.
    Таб = Новый ТабличныйДокумент;
    Для Кол = 0 По ТЗ.Колонки.Количество() - 1 Цикл
        Таб.Область(1, Кол + 1).Текст = ТЗ.Колонки[Кол].Имя;
    КонецЦикла;
    НомерСтроки = 2;
    Для Каждого Стр Из ТЗ Цикл
        Для Кол = 0 По ТЗ.Колонки.Количество() - 1 Цикл
            Таб.Область(НомерСтроки, Кол + 1).Текст =
                Стр[ТЗ.Колонки[Кол].Имя];
        КонецЦикла;
        НомерСтроки = НомерСтроки + 1;
    КонецЦикла;
    Таб.Записать(ПутьКФайлу, ТабличныйДокументТипФайла.XLSX);

КонецПроцедуры
```

Вызов — как у остальных выгрузок, с путём в папку синхронизации Drive:

```bsl
ВыгрузитьПланСчетов("C:\...\ДискGoogle\<папка фирмы>\Хайджин_УПРАВЛЕНКА_План счетов.xlsx");
```

## Проверка результата

- Строк ориентировочно 200–400 (в журнале проводок Хайджин задействовано
  всего 75 счетов — остальные просто ни разу не использовались).
- В файле Инновейв обязаны быть **1540**, **3430**, **8100**, **3410** и
  счёт налога с продаж — если их нет, выгрузили не ту базу.
- У счетов 1610, 1410, 3110, 6110, 7210 в колонках субконто должны стоять
  «Номенклатура», «Контрагенты», «Статьи затрат» и т.п. — это то, ради чего
  всё и делается: по субконто портал строит расшифровки.

## Что портал будет с этим делать

1. Названия строк в ОСВ, Балансе и P&L — из плана счетов, а не из кода.
2. Группировка по разделам (1000 активы, 3000 обязательства и т.д.) с
   учётом иерархии (`Родитель`).
3. Проверка: счёт в проводке, которого нет в плане счетов → сигнал, что
   выгрузки из разных баз перепутаны.
4. У Инновейв — отдельный блок налоговых счетов для раздела «НДС».
