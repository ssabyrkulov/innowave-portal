# ТЗ для Ермека — доработка выгрузки реализации (ВыгрузкаРеал2)

Контекст: портал уже считает по этой выгрузке продажи. Теперь хотим ещё
**прибыль/маржу** и **полный контроль проводок** — для этого нужно добавить
несколько колонок.

## Важно (чтобы ничего не сломать)

- **Имя файла оставить прежним — `ВыгрузкаРеал2.xlsx`.** Портал распознаёт
  выгрузку по имени; переименование сломает автозагрузку.
- **Одна строка = одна строка табличной части реализации** (как сейчас).
- **Существующие колонки и их заголовки не менять и не удалять.** Новые
  колонки добавить **в конец** — порядок значения не имеет, читаем по имени.

## Оставить как есть (уже используем)

`Дата` · `КонтрагентНаименование` · `Склад` · `НоменклатураНаименование` ·
`Количество` · `Цена` · `Сумма` · `ВалютаДокументаНаименование` · `Номер` ·
`СуммаДокумента` · `ПроцентСкидкиНаценки` · `СчётУчёта` (1610) ·
`ОтветственныйНаименование` (или `ОтветственныйФИО`) ·
`КонтрагентSD_АгентНаименование`.

## Добавить колонки

| Колонка | Что это | Формат |
|---|---|---|
| **Себестоимость** | Сумма себестоимости по строке (списание Дт 7210 — Кт 1610). **Главное поле — без него не посчитать прибыль.** | число, сомы |
| **СчётДоходов** | Счёт доходов из проводки реализации (напр. 6110) | код |
| **СтатьяДоходовНаименование** | Статья доходов | текст |
| **СчётРасходов** | Счёт себестоимости из проводки (напр. 7210) | код |
| **СтатьяРасходовНаименование** | Статья расходов (себестоимости) | текст |
| **ОрганизацияНаименование** | Фирма: Innowave Hygiene / Innowave (чтобы не смешивать организации) | текст |

## Примечания по формату

- **Себестоимость** — число в сомах, по каждой строке. При **непрерывном**
  методе учёта она есть сразу при проведении реализации — это нам подходит.
  Если за текущий незакрытый месяц себестоимость по каким-то строкам не
  рассчитана (0/пусто) — так и оставить, мы это учтём.
- **Счета** — лучше кодом (6110 / 7210). **Статьи** — наименованием.
- Суммы/валюта — как сейчас (сом); разделители разрядов неважны.
- Добавление колонок импорт не ломает — портал читает по названию колонки,
  недостающие поля просто игнорируются, пока не появятся.

## Зачем это нам (коротко)

- **Себестоимость** → прибыль и маржа по товару, клиенту, агенту; отчёт БДР.
- **Счёт/статья доходов и расходов** → контроль правильности проводок
  (пустой счёт/статья, не тот счёт) и построение ОПиУ по статьям.
- **Организация** → раздельный и консолидированный учёт по двум фирмам.
