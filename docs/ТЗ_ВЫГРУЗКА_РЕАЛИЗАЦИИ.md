# ТЗ для Ермека — выгрузка реализации (ВыгрузкаРеал2)

Портал считает по этой выгрузке продажи; добавляем **прибыль/маржу** и
**контроль проводок**. Ниже — итоговый состав выгрузки.

## Важно (чтобы не сломать автозагрузку)

- **Имя файла — прежнее: `ВыгрузкаРеал2.xlsx`** (портал распознаёт по имени).
- **Одна строка = одна строка табличной части реализации.**
- Существующие колонки и заголовки **не менять и не удалять**; новые — **в конец**.

## Примечания по формату

- **Себестоимость** — число в сомах, по строке. При непрерывном методе есть
  сразу при проведении. Если за текущий незакрытый месяц по каким-то строкам
  не рассчитана (0/пусто) — так и оставить.
- Счета — кодом (6110 / 7210); статьи — наименованием.
- Добавление колонок импорт не ломает — читаем по названию колонки.
- Колонку 13 (ед. измерения) можно убрать — всегда «шт», не используется;
  но и оставить не мешает.

## Зачем (коротко)

- 16 → прибыль и маржа по товару/клиенту/агенту, отчёт БДР.
- 17–20 → контроль правильности проводок и ОПиУ по статьям.
- 21 → раздельный и консолидированный учёт по двум фирмам.
