## Шаг 0. Включить новый пакет в работу (сегодня, почти без кода)

Пакет `Хайджин_УПРАВЛЕНКА_*` лежит в папке `INNOWAVE GROUP UPLOAD`, а
автосинк смотрит на папку фирмы. Достаточно **положить файлы в рабочую
папку Хайджин** — и существующие импортёры сразу дадут то, чего не хватало:

- ДокументGUID в реализациях (было 0%, станет 100%) → сверка по ID
  перестаёт гадать;
- себестоимость в каждой строке → валовая прибыль;
- наличные оплаты из ПКО (1 593 документа на 42,75 млн) → дебиторка
  перестаёт завышаться;
- КонтрагентGUID и НоменклатураGUID → сверка с SalesDoc по ключу.

Проверка после загрузки: **Контроль → Журнал загрузок** — все файлы
распознаны, ничего не в «не распознан». Часть видов (журнал проводок,
справочники, ГТД, зарплата и др.) пока попадёт в «нет импортёра» — это
нормально, они ждут шага 1.

**Владелец: вы.** Занимает 5 минут.

## Шаг 1. Данные: импортёры под новые виды (я)

По ценности:

1. **План счетов** — справочник счетов с субконто и признаками (оба файла
   уже есть). Без него отчёты нельзя строить по-человечески.
2. **Журнал проводок** — ядро. Открывает ОСВ, Баланс, P&L, сверку ДДС.
3. **Проблемные документы** — фильтр для всех остальных расчётов.
4. **Контрагенты и номенклатура** — GUID-связка с SalesDoc.
5. Дальше по мере надобности: ГТД + допрасходы (landed cost), зарплата,
   авансовые отчёты, конвертация, инвентаризация, оприходование,
   перемещения.

Плюс правки классификатора под новые имена файлов.

## Шаг 2. Финансы: отчёты из журнала (я)

Строго в этом порядке — каждый следующий опирается на предыдущий:

1. **ОСВ** за период (обороты и сальдо по счетам, клик → проводки);
2. **P&L** помесячно (выручка, себестоимость, расходы по статьям; обороты
   **без** документов закрытия месяца);
3. **Баланс** на дату (учёт начат с нуля 25.09.2024, вводных остатков не
   нужно);
4. **ДДС**: факт по статьям + сверка с оборотами 1110/1210/1220.

## Шаг 4. Инновейв (после шага 1)
