# ВыгрузкаОст: код для нашей обработки 1С

Плоская выгрузка остатков товаров — в тот же модуль, где уже живут
ВыгрузкаПост и ВыгрузкаСпис. Не зависит от штатного отчёта 1С.

Формат — одна строка на «товар × склад»:

| СкладНаименование | НоменклатураНаименование | НоменклатураGUID | КоличествоОстаток | СуммаОстаток |
|---|---|---|---|---|

Портал принимает файл как есть (плоский разбор по именам колонок уже
включён). `НоменклатураGUID` — важная колонка: по ней товар связывается с
SalesDoc по идентификатору, а не по названию. Файл называть `ВыгрузкаОст.xlsx`
и класть в ту же папку Drive, что и остальные выгрузки фирмы.

## Код (скопировать в модуль обработки)

```bsl
// Остатки товаров на складах — плоской таблицей, для портала.
// Источник — регистр бухгалтерии, счёт учёта товаров (1610): та же
// картина, что в оборотке, без посредничества штатного отчёта.
Процедура ВыгрузитьОстаткиТоваров() Экспорт

    ПутьКФайлу = "C:\Выгрузки\ВыгрузкаОст.xlsx";   // куда сохранить
    КодСчета   = "1610";                            // счёт учёта товаров
    НаДату     = КонецДня(ТекущаяДата());           // остатки на конец сегодня

    Счет = ПланыСчетов.Хозрасчетный.НайтиПоКоду(КодСчета);
    Если Счет.Пустая() Тогда
        Сообщить("Счёт " + КодСчета + " не найден — проверьте код.");
        Возврат;
    КонецЕсли;

    Запрос = Новый Запрос;
    Запрос.Текст =
    "ВЫБРАТЬ
    |   Ост.Субконто1 КАК Номенклатура,
    |   Ост.Субконто2 КАК Склад,
    |   Ост.КоличествоОстатокДт КАК Количество,
    |   Ост.СуммаОстатокДт КАК Сумма
    |ИЗ
    |   РегистрБухгалтерии.Хозрасчетный.Остатки(&НаДату, Счет = &Счет, , ) КАК Ост
    |ГДЕ
    |   (Ост.КоличествоОстатокДт <> 0 ИЛИ Ост.СуммаОстатокДт <> 0)
    |УПОРЯДОЧИТЬ ПО
    |   Склад, Номенклатура";
    Запрос.УстановитьПараметр("НаДату", НаДату);
    Запрос.УстановитьПараметр("Счет", Счет);

    ТабДок = Новый ТабличныйДокумент;
    Шапка = "СкладНаименование,НоменклатураНаименование,НоменклатураGUID," +
            "КоличествоОстаток,СуммаОстаток";
    Колонки = СтрРазделить(Шапка, ",");
    Для Н = 0 По Колонки.ВГраница() Цикл
        ТабДок.Область("R1C" + Формат(Н + 1, "ЧГ=0")).Текст = Колонки[Н];
    КонецЦикла;

    Стр = 1;
    Выборка = Запрос.Выполнить().Выбрать();
    Пока Выборка.Следующий() Цикл
        Стр = Стр + 1;
        ТабДок.Область("R" + Формат(Стр, "ЧГ=0") + "C1").Текст =
            Строка(Выборка.Склад);
        ТабДок.Область("R" + Формат(Стр, "ЧГ=0") + "C2").Текст =
            Строка(Выборка.Номенклатура);
        ТабДок.Область("R" + Формат(Стр, "ЧГ=0") + "C3").Текст =
            Строка(Выборка.Номенклатура.УникальныйИдентификатор());
        // Числа пишем ЗНАЧЕНИЕМ, не текстом: текст уехал бы с запятой
        // и пробелами локали, и портал прочёл бы его неверно.
        ОблК = ТабДок.Область("R" + Формат(Стр, "ЧГ=0") + "C4");
        ОблК.СодержитЗначение = Истина;
        ОблК.Значение = Выборка.Количество;
        ОблС = ТабДок.Область("R" + Формат(Стр, "ЧГ=0") + "C5");
        ОблС.СодержитЗначение = Истина;
        ОблС.Значение = Выборка.Сумма;
    КонецЦикла;

    ТабДок.Записать(ПутьКФайлу, ТипФайлаТабличногоДокумента.XLSX);
    Сообщить("Остатки выгружены: " + Формат(Стр - 1, "ЧГ=0") + " строк → " + ПутьКФайлу);

КонецПроцедуры
```

## Что проверить при первом запуске

1. **Порядок субконто.** Если в колонке «Номенклатура» оказались названия
   складов — поменять в запросе `Субконто1` и `Субконто2` местами (порядок
   субконто на счёте 1610 отличается между конфигурациями).
2. **Имя плана счетов и регистра.** В коде — типовой `Хозрасчетный`; если в
   вашей конфигурации имя иное, 1С скажет об этом при первом запуске —
   поправить в двух местах.
3. **Обе фирмы.** Если учёт двух фирм в одной базе — добавить в вирт. таблицу
   условие `Организация = &Организация` и выгружать два файла в свои папки.

## Если конфигурация без бухгалтерского регистра

В торговых конфигурациях (УТ/УНФ) вместо регистра бухгалтерии — регистр
накопления, текст запроса тогда такой (суммы там нет — только количество,
колонка СуммаОстаток уйдёт нулями, портал это переживёт):

```bsl
    |ВЫБРАТЬ
    |   Ост.Номенклатура КАК Номенклатура,
    |   Ост.Склад КАК Склад,
    |   Ост.ВНаличииОстаток КАК Количество,
    |   0 КАК Сумма
    |ИЗ
    |   РегистрНакопления.ТоварыНаСкладах.Остатки(&НаДату, ) КАК Ост
```
