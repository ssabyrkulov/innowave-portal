# InnoWave Group — Платёжный календарь

Веб-приложение для планирования и контроля платежей компании с управлением
пользователями и правами доступа.

- **Backend:** FastAPI + SQLAlchemy (SQLite), JWT-авторизация, RBAC
- **Frontend:** React (Vite), календарь платежей, таблицы, управление пользователями

## Возможности

- 📅 **Календарь платежей** — помесячный вид с входящими/исходящими платежами,
  суммами и статусами; быстрый ввод платежа по клику на дату.
- 📋 **Список платежей** — таблица с фильтрами по направлению и статусу,
  создание/редактирование/удаление.
- 💰 **Сводка по месяцу** — поступления, списания и баланс.
- 👥 **Пользователи и роли** — администратор управляет учётными записями.
- 🔐 **Права доступа (RBAC)** — три роли:

| Роль | Календарь и платежи | Создание/редактирование платежей | Управление пользователями |
|------|:---:|:---:|:---:|
| **Администратор** (admin) | ✅ | ✅ | ✅ |
| **Бухгалтер** (accountant) | ✅ | ✅ | ❌ |
| **Наблюдатель** (viewer) | ✅ (только чтение) | ❌ | ❌ |

## Структура проекта

```
backend/    FastAPI-приложение (API, модели, авторизация)
frontend/   React-приложение (Vite)
```

## Запуск backend

```bash
cd backend
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env          # при необходимости отредактируйте
uvicorn app.main:app --reload
```

API поднимется на http://localhost:8000 (Swagger — http://localhost:8000/docs).

При первом запуске автоматически создаётся учётная запись администратора
из `.env` (по умолчанию `admin@innowave.group` / `admin123`).
**Смените пароль и `SECRET_KEY` перед использованием.**

## Запуск frontend

```bash
cd frontend
npm install
npm run dev
```

Приложение откроется на http://localhost:5173. Запросы к `/api/*`
проксируются на backend (http://localhost:8000) — см. `vite.config.js`.

## Модель платежа

| Поле | Описание |
|------|----------|
| `title` | Название платежа |
| `amount` / `currency` | Сумма и валюта (KGS, USD, EUR, RUB, KZT) |
| `direction` | `incoming` (входящий) / `outgoing` (исходящий) |
| `status` | `planned` / `paid` / `overdue` |
| `due_date` | Дата платежа |
| `counterparty` | Контрагент (необязательно) |
| `category` | Статья (необязательно) |
| `note` | Комментарий (необязательно) |

## Безопасность

- Пароли хранятся в виде bcrypt-хэшей.
- Доступ к API защищён JWT-токенами (срок жизни настраивается в `.env`).
- Проверка прав выполняется на стороне сервера для каждого защищённого эндпоинта;
  ограничения в интерфейсе — лишь для удобства.

Перед продакшеном: задайте надёжный `SECRET_KEY`, смените пароль администратора,
ограничьте `allow_origins` в CORS и при необходимости переключите БД на PostgreSQL
(`DATABASE_URL`).
